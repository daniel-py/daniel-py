## Apps

## Backend

I built a Go REST API (Gin, PostgreSQL on Neon) with JWT auth, plan-based access and Paystack subscription billing
with an auto-renewal worker, deployed on Fly.io with Docker, and the Flutter client on top of it
([code](https://github.com/daniel-py/jira_copycat)). My earlier Python backends are a
[Flask WhatsApp assistant](https://github.com/daniel-py/whatsapp_bot) on Twilio and a
[Django website](https://github.com/daniel-py/My-Web-Project).

## AI

I contributed to building the Sumeru series of open-weight models for Indian education, which covers small tutors
that run offline, reasoning models, voice and vision. I also built the on-device AI in EdgeExl, a fully offline
learning app, with local LLM and vision-language inference through OpenVINO, offline retrieval (RAG) and a local
voice loop. In my independent projects I've fine-tuned Qwen2.5 models with QLoRA
([code](https://github.com/daniel-py/yoruba-and-maths-finetuning)) and published the
[Yoruba Academic Wikipedia QA dataset](https://huggingface.co/datasets/Remithefirst/yoruba-academic-wikipedia-qa)
on Hugging Face.

live streaming.
